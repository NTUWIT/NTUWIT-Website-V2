# NTU Women in Tech

Official website for NTU Women in Tech, building the next generation of tech leaders through flagship events, mentorship, and community.

## Getting Started

Install dependencies with yarn:

```bash
yarn install
```

Start the development server:

```bash
yarn dev
```

The site will be available at `http://localhost:3000`

## Build

```bash
yarn build
```

## Technology Stack

- **Next.js** + **React** + **TypeScript** - Framework, Routing, and UI
- **Tailwind CSS** — Styling
- **Three.js** — 3D graphics
